# Денежный поток 202 — Мобильная игра

Полная реализация настольной игры Robert Kiyosaki «Cashflow 202» для iPhone (Expo Go).
Одиночная игра против 1–5 ИИ-ботов. Весь интерфейс на русском.

---

## 📱 Запуск на iPhone через Expo Go

### 1. Установить Expo Go

Скачай приложение **Expo Go** из App Store на iPhone.

### 2. Запустить dev-сервер

```bash
cd cashflow202
npx expo start
```

### 3. Открыть на iPhone

Открой **камеру** iPhone и наведи на **QR-код** в терминале.
Нажми на появившуюся ссылку — откроется Expo Go с игрой.

> **Важно:** iPhone и компьютер должны быть в **одной WiFi-сети**.

### Если разные сети (мобильный интернет):

```bash
npx expo start --tunnel
```

---

## 🎮 Как играть

1. Главное меню → **Новая игра**
2. Выбери профессию, мечту, число ботов и уровень сложности
3. Нажимай **Бросить!** на игровом поле для хода
4. Следи за **Финансовым отчётом** (вкладка «Отчёт»)
5. Для опционов/шорта → кнопка **📈** (биржа)
6. Выйди из Крысиных бегов: доведи пассивный доход > расходов
7. На Скоростной дорожке купи Мечту или нарасти доход +$50 000/мес

## 🧠 Механики 202

| Инструмент | Описание |
|---|---|
| **Опцион колл** | Право купить акцию по strike, если цена вырастет за 3 рыночных события |
| **Опцион пут** | Право продать по strike, если цена упадёт |
| **Короткая продажа** | Замораживаем маржу, зарабатываем на падении |
| **Страддл** | Колл + пут одновременно, ставка на резкое движение |

Все параметры (премии, срок, порог шорта) — в `src/data/config.ts`.

---

## 👾 ИИ-боты

| Уровень | Поведение |
|---|---|
| **Лёгкий** | Покупает только позитивный поток, не использует опционы |
| **Средний** | + скупает акции у нижней границы, продаёт у верхней |
| **Сложный** | + использует колл/пут/шорт/страддл, оптимизирует выход |

Ходы ботов — автоматически с задержкой 800 мс. Все действия в логе.
