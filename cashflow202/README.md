# Денежный поток 202 — Мобильная игра

Реализация настольной игры Robert Kiyosaki «Cashflow 202» для iPhone (Expo Go).

## Запуск на iPhone через Expo Go

### 1. Установить Expo Go

Скачай приложение **Expo Go** из App Store на iPhone.

### 2. Запустить проект

```bash
cd cashflow202
npx expo start
```

### 3. Открыть на iPhone

- В терминале появится **QR-код**.
- Открой **камеру** iPhone и наведи на QR-код.
- Нажми на появившуюся ссылку — откроется Expo Go с игрой.

> Телефон и компьютер должны быть в **одной WiFi-сети**.

### Альтернатива (туннель)

```bash
npx expo start --tunnel
```

Работает через разные сети (мобильный интернет на телефоне — ок).

## Разработка

```bash
npm install          # установить зависимости
npx expo start       # запуск dev-сервера
npm test             # Jest тесты движка
```

## Архитектура

```
app/            — экраны (expo-router)
src/engine/     — чистый TS движок правил (Jest-тесты)
src/data/       — данные: профессии, сделки, акции, конфиг
src/ai/         — логика ИИ-ботов
src/state/      — Zustand стор + AsyncStorage
src/types/      — TypeScript типы
__tests__/      — Jest тесты
```
